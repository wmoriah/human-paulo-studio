# Código de Conduta

Este é um espaço de colaboração aberta. Para todos se sentirem bem aqui:

- Seja respeitoso e gentil. Críticas são para o trabalho, nunca para a pessoa.
- Sem assédio, discriminação, ataques pessoais ou spam.
- Dê crédito a quem criou o conteúdo original.
- Não publique dados pessoais de terceiros.

Comportamentos que violem estas regras podem levar a remoção de comentários, issues ou PRs e ao bloqueio de participantes. Para reportar, abra uma issue ou fale com o mantenedor [@wmoriah](https://github.com/wmoriah).
