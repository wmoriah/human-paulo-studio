# Character Sheet Studio — entrada Codex

Esta pasta é um fluxo pronto para criar um character sheet; não é um pedido para desenvolver software.
Ao usuário dizer “começar”, “iniciar”, “leia a pasta”, “leia as instruções” ou pedir o character sheet, leia `SKILL.md` nesta pasta e execute seu fluxo conversacional. Primeiro solicite as referências faltantes, depois pergunte rota/modelo, conecte se necessário e produza o board. Não responda apenas com um resumo dos arquivos ou um plano. Se já houver fotos, aproveite-as. Se pedir apenas auditoria/explicação, respeite esse escopo.
Se o usuário pedir instalação como skill, siga a seção Instalação de `SKILL.md`. Abrir/ler a pasta não autoriza instalação global. Mantenha as fotos faciais originais fora de qualquer geração; gere só os corpos e componha localmente. Não inicie geração paga enquanto aguarda a escolha de rota/modelo.

Versão 2: manter quatro vistas. Remover apenas cenário por máscara separada é permitido; não gerar/retocar o rosto nem modificar RGB original. Seguir references/framing.md: medir a cabeça, fazer close-up por viewport e inspecionar máscaras. Não encaixar as fotografias inteiras nas laterais.
